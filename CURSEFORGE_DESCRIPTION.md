# GeoTetraArmor PneumaticCraft Compat

## English

Bring PneumaticCraft's pneumatic armor systems to GeoTetraArmor as Tetra attachments.

### Features

- Adds pneumatic attachments for the `head/extra`, `chest/extra`, `legs/extra`, and `feet/extra` slots.
- Only armor with the matching attachment can store air, use PNC upgrades, display the HUD and tooltips, or access armor settings.
- Installing an attachment consumes the matching PNC armor piece and preserves its air, upgrades, settings, and colors.
- Removing or replacing an attachment returns the matching PNC armor piece with its current state.
- Supports the Charging Station and PNC armor functions for each equipment slot.

### Requirements

- Minecraft 1.20.1
- Forge
- Tetra
- GeoTetraArmor
- PneumaticCraft: Repressurized

Install this mod and all required dependencies on both the client and server.

## 中文

将 PneumaticCraft 的气动护甲系统作为 Tetra 附件加入 GeoTetraArmor。

### 功能

- 为 `head/extra`、`chest/extra`、`legs/extra` 和 `feet/extra` 槽位添加气动附件。
- 只有安装对应附件的护甲才能储气、使用 PNC 升级、显示 HUD 与提示，并打开护甲设置。
- 安装附件会消耗对应的 PNC 护甲，并继承气量、升级、设置和颜色。
- 拆除或替换附件时，会返还保留当前状态的对应 PNC 护甲。
- 支持充能站及各装备槽位对应的 PNC 护甲功能。

### 前置模组

- Minecraft 1.20.1
- Forge
- Tetra
- GeoTetraArmor
- PneumaticCraft: Repressurized

客户端和服务端均需安装本模组及全部前置模组。
